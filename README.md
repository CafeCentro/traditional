# CafeCentro Traditional

CafeCentro Traditional client installer releases.

Download the latest `traditional-setup.exe` from the repository releases page.

## Install

1. Download `traditional-setup.exe`.
2. Run the installer as administrator.
3. Enter the store address and PC number from CafeCentro.

## Notes

- Installer binaries are published as GitHub Release assets.
- Source and build artifacts are managed outside this distribution repository.
